Trouver un nom et une identité à l'extension

Les six designs encore en lice : Octane en Pétrole, Supercharged GitHub en Cobalt et en Boost, et Amplified GitHub en Circuit, Onde et VU-mètre. Chacun avec logo, palette, typo, icône dans la barre d'outils, vignette du store et page d'options.

Les noms

Le risque mesure la probabilité qu'une revue du Chrome Web Store ou d'AMO bloque la fiche parce que le nom laisse croire à un produit officiel de GitHub.

Nom Schéma Risque store Pourquoi
Octane for GitHub X for GitHub faible Le carburant, avec « octo » en clin d'œil à l'Octocat. Court, se prononce pareil en français et en anglais.
Supercharged GitHub Adj. GitHub moyen « Suralimenté » : garde l'idée de puissance du nom actuel. Refined GitHub est publié sous ce schéma depuis des années.
Amplified GitHub Adj. GitHub moyen La même idée de puissance, version électrique. Plus calme que Supercharged.

Mon choix : Octane for GitHub (Pétrole). C'est le seul nom en lice à risque faible, et le nom tient seul (repo octane, id Gecko octane@vmaerten) : « for GitHub » se retire sans rien renommer si un store bloque.

Si tu préfères garder « GitHub » collé au nom : Supercharged GitHub en Cobalt, ou Amplified GitHub en VU-mètre si tu veux encore plus sobre.

Où la charte s'applique

Icône, options, stores, README

Toute la charte : logo, palette, typos. C'est là qu'on reconnaît l'extension.

UI injectée dans GitHub

Primer uniquement : variables CSS de GitHub, octicons, police système. Un bouton aux couleurs de la marque dans une PR détonnerait et casserait les thèmes de GitHub.

Manifest

Icônes PNG en 16, 32, 48 et 128 générées depuis le SVG. Le 16 px doit rester lisible sur les barres d'outils claires comme sombres.

À trancher

  1. Lequel des six ? On peut aussi mélanger, par exemple le logo d'un design avec la palette d'un autre.
  2. Une fois le choix fait : renommer le repo, le manifest et l'id Gecko, générer les icônes PNG et habiller la page d'options.
Cliquer sur une couleur copie son code hexadécimal.
