Trouver un nom et une identité à l'extension

La short list : Octane en Pétrole, Supercharged GitHub en Cobalt et en Boost. Chacun avec logo, palette, typo, icône dans la barre d'outils, vignette du store et page d'options. Choix final : Supercharged GitHub en Boost, avec le logo P3 des pistes poulpe.

Les noms

Le risque mesure la probabilité qu'une revue du Chrome Web Store ou d'AMO bloque la fiche parce que le nom laisse croire à un produit officiel de GitHub.

Nom Schéma Risque store Pourquoi
Octane for GitHub X for GitHub faible Le carburant, avec « octo » en clin d'œil à l'Octocat. Court, se prononce pareil en français et en anglais.
Supercharged GitHub Adj. GitHub moyen « Suralimenté » : garde l'idée de puissance du nom actuel. Refined GitHub est publié sous ce schéma depuis des années.

Choix : Supercharged GitHub, palette Boost, logo P3 (trois bras à ventouses). Risque moyen au passage des stores, le même schéma que Refined GitHub. Si un store bloque le nom, Octane for GitHub en Pétrole reste le plan B.

Supercharged GitHub · Cobalt, pistes poulpe

Un clin d'œil à la pieuvre de GitHub sans reprendre l'Octocat : les règles d'usage des marques GitHub interdisent de l'utiliser ou de le modifier dans le logo d'un autre produit, et une revue de store peut le refuser. Les quatre pistes gardent la palette Cobalt et se jugent surtout à 16 px, dans la barre d'outils.

Référence · turbine actuelle

La roue de turbine à cinq pales du design Cobalt, pour comparer.

P1 · Turbine à huit bras

Huit pales, comme les huit bras, chacune terminée par une petite boucle de tentacule. Reste une turbine de loin.

P2 · Poulpe

Une tête ronde, deux yeux et quatre bras. Le plus lisible comme poulpe, le plus ludique aussi.

P3 · Trois bras à ventouses

Trois bras épais en spirale, comme une hélice, avec des ventouses. Le plus lisible à 16 px.

P4 · S tentacule

Le S de Supercharged dessiné comme un bras avec ses ventouses, la pointe enroulée.

Où la charte s'applique

Toute la charte : logo, palette, typos. C'est là qu'on reconnaît l'extension.

UI injectée dans GitHub

Primer uniquement : variables CSS de GitHub, octicons, police système. Un bouton aux couleurs de la marque dans une PR détonnerait et casserait les thèmes de GitHub.

Manifest

Icônes PNG en 16, 32, 48 et 128 générées depuis le SVG. Le 16 px doit rester lisible sur les barres d'outils claires comme sombres.
