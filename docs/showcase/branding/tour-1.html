Trouver un nom et une identité à l'extension

Quatre directions, chacune avec son nom, son logo, sa palette, sa typo, et un aperçu de l'icône dans la barre d'outils, de la fiche store et de la page d'options. « GitHub » est autorisé dans le nom ; le risque est noté pour chaque candidat.

Les noms

Avec « GitHub » autorisé, trois schémas sont possibles. Le risque mesure la probabilité qu'une revue du Chrome Web Store ou d'AMO bloque la fiche parce que le nom laisse croire à un produit officiel.

Nom Schéma Risque store Pourquoi
Nom propre + for GitHub
Octane for GitHub X for GitHub faible Le carburant, avec « octo » en clin d'œil à l'Octocat. Court, se prononce pareil en français et en anglais.
Ninth Arm for GitHub X for GitHub faible Le neuvième bras de la pieuvre, celui qu'elle n'a pas de série. Le plus mémorable, mais il faut l'expliquer.
★ Whetstone for GitHub X for GitHub faible La pierre à aiguiser. Sobre et outillé, mais moins drôle.
Adjectif + GitHub (comme Refined GitHub)
Supercharged GitHub Adj. GitHub moyen « Suralimenté » : on garde l'idée de puissance du nom actuel. Refined GitHub est publié sous ce schéma depuis des années sur les deux stores, ce qui le rend plausible. Charte : direction D.
Overclocked GitHub Adj. GitHub moyen GitHub poussé au-delà de ses réglages d'usine. Un peu long à taper.
Sharpened GitHub Adj. GitHub moyen Va bien avec la direction Whetstone si on préfère ce schéma.
GitHub + nom
GitHub Power GitHub X élevé Le nom actuel. Ressemble à une fonctionnalité officielle, comme GitHub Copilot ou GitHub Actions.
GitHub Octane GitHub X élevé Même problème : on dirait un produit GitHub.

Mon choix : Whetstone for GitHub, direction C. Tu veux un outil pro et sobre, publié sur les stores : c'est la direction la plus calme, et le schéma « X for GitHub » est le moins exposé à un refus. Le nom tient seul (repo whetstone, id Gecko whetstone@vmaerten), donc « for GitHub » se retire sans rien renommer si un store bloque.

Si tu tiens à l'idée de puissance du nom actuel : Supercharged GitHub, direction D, avec un risque store moyen.

Direction D · Puissance · pro

Supercharged GitHub

More power to your pull requests.

Le compresseur qui suralimente un moteur : une roue de turbine cobalt sur fond encre et papier, rien d'autre. « Supercharged » porte la marque et « GitHub » est composé plus léger, pour qu'on lise d'abord le nom de l'extension. Ni pieuvre ni Octocat : la marque GitHub n'apparaît que dans le texte.

Où la charte s'applique

Icône, options, stores, README

Toute la charte : logo, palette, typos. C'est là qu'on reconnaît l'extension.

UI injectée dans GitHub

Primer uniquement : variables CSS de GitHub, octicons, police système. Un bouton aux couleurs de la marque dans une PR détonnerait et casserait les thèmes de GitHub.

Manifest

Icônes PNG en 16, 32, 48 et 128 générées depuis le SVG. Le 16 px doit rester lisible sur les barres d'outils claires comme sombres.

À trancher

  1. Quelle direction : A, B, C ou D ? On peut aussi en mélanger deux, par exemple un nom avec la palette d'une autre direction.
  2. Quel schéma de nom : « X for GitHub », ou un adjectif à la Refined GitHub ?
  3. Une fois le choix fait : renommer le repo, le manifest et l'id Gecko, générer les icônes PNG et habiller la page d'options.
