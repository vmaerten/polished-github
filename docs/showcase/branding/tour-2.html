Trouver un nom et une identité à l'extension

Deux familles retenues, Octane et Supercharged GitHub, avec trois variantes chacune : logo, palette, typo, icône dans la barre d'outils, vignette du store et page d'options. Ninth Arm reste en fin de page pour comparer.

Les noms

Le risque mesure la probabilité qu'une revue du Chrome Web Store ou d'AMO bloque la fiche parce que le nom laisse croire à un produit officiel de GitHub.

Nom Schéma Risque store Pourquoi
Nom propre + for GitHub
★ Octane for GitHub X for GitHub faible Le carburant, avec « octo » en clin d'œil à l'Octocat. Court, se prononce pareil en français et en anglais. Trois variantes plus bas.
Torque for GitHubnouveau X for GitHub faible Le couple moteur : la force qui fait avancer, plutôt que la vitesse de pointe. Sobre, un seul mot, se dit pareil en français.
Ninth Arm for GitHub X for GitHub faible Le neuvième bras de la pieuvre. Le plus mémorable, mais plus ludique que pro.
Adjectif + GitHub (comme Refined GitHub)
Supercharged GitHub Adj. GitHub moyen « Suralimenté » : garde l'idée de puissance du nom actuel. Refined GitHub est publié sous ce schéma depuis des années. Trois variantes plus bas.
Amplified GitHubnouveau Adj. GitHub moyen Même idée de puissance, version électrique plutôt que mécanique. Plus calme que Supercharged.
Overclocked GitHub Adj. GitHub moyen GitHub poussé au-delà de ses réglages d'usine. Un peu long à taper.
GitHub + nom
GitHub Power GitHub X élevé Le nom actuel. Ressemble à une fonctionnalité officielle, comme GitHub Copilot ou GitHub Actions.

Mon choix : Octane for GitHub, variante 2 (Octogone). C'est la plus sobre des six, l'octogone se lit en 16 px sur les deux barres d'outils, et « X for GitHub » est le schéma le moins exposé à un refus. Le nom tient seul (repo octane, id Gecko octane@vmaerten), donc « for GitHub » se retire sans rien renommer si un store bloque.

Côté Supercharged GitHub, je prendrais la variante 1 (Cobalt), avec un risque store moyen.

Où la charte s'applique

Icône, options, stores, README

Toute la charte : logo, palette, typos. C'est là qu'on reconnaît l'extension.

UI injectée dans GitHub

Primer uniquement : variables CSS de GitHub, octicons, police système. Un bouton aux couleurs de la marque dans une PR détonnerait et casserait les thèmes de GitHub.

Manifest

Icônes PNG en 16, 32, 48 et 128 générées depuis le SVG. Les chiffres et lettres des logos (« 98 », « S ») seront vectorisés pour ne pas dépendre d'une police.

À trancher

  1. Octane ou Supercharged GitHub ? Ou Torque, Amplified GitHub, qui n'ont pas encore de charte ?
  2. Quelle variante dans la famille retenue ? On peut aussi mélanger, par exemple le logo d'une variante avec la palette d'une autre.
  3. Une fois le choix fait : renommer le repo, le manifest et l'id Gecko, générer les icônes PNG et habiller la page d'options.
