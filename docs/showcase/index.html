Décidé

  • Supercharged GitHub en palette Boost, avec le logo P3.
  • Manrope et JetBrains Mono pour le site, comme pour la page d'options.
  • Astro pour le site, avec une page par feature générée depuis un fichier Markdown.
  • Structure L pour l'accueil, plus le catalogue et les pages par feature.
  • Badges en colonne de droite par défaut, la ligne grise en option.
  • Compteur à droite pour la charge des reviewers.
