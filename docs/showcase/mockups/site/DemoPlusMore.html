Questions

Why does it need a token?

The PR list badges and the reviewer load ask the GitHub API for data the page does not show. Quick comments and the image modal work without one.

Does it work alongside Refined GitHub?

Yes. The two run side by side.

Try it on your own PR list

Needs a read-only GitHub token, kept in your browser.
