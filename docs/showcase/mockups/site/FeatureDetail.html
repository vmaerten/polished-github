Features / Triage

Review status

Where each pull request stands for you, on every row of the PR list. You stop opening PRs just to find out whether you already reviewed them.

Appears in: PR list Needs token On by default

What each status means

Review requested
You are asked and have not reviewed yet.
Re-review
You reviewed, then the author pushed or asked you again.
Changes requested
You asked for changes and nothing has moved since.
Approved · new commits
You approved, and commits landed after your approval.

A plain approval gets no badge: GitHub already shows it.

Settings

Badge placement Right column (default) or the grey line under the title. Shared by all PR list badges.
Turn off Options › Features › Review status

Good to know

  • Statuses are fetched again on every visit, so they are never stale.
  • A review you started but did not submit counts as no review.
  • Needs a token with read access to Pull requests.
