Browser extension for Chrome and Firefox

Review pull requests faster, right on GitHub.

See where every PR stands for you, pick the reviewer who has room, and answer in one click. No new tab, no new tool.

Add to Chrome Add to Firefox

Every feature can be turned off · Your token stays in your browser

In the PR list

Know what needs you before opening a PR

A quiet column on each row: lines added and removed with a size label, where the PR stands for you, and how long it has been idle.

  • Review requested, re-review, changes requested, approved but changed since
  • Idle for N days, threshold of your choice, drafts optional
  • In the right column or in the grey line under the title

In the reviewers picker

Pick the reviewer who has room

Next to each name, how many reviews that person already has waiting in this organization. The counter turns amber at 3 and orange past 5.

Quick comments

Answer in one click

Buttons above the comment box post the replies you write ten times a day. LGTM, ask a bot to rebase, say thanks: the list is yours to edit.

Image modal

Look at screenshots without losing your place

Images in issues, PRs and READMEs open in a zoomable modal instead of a new tab. Arrow keys go through the comment's images.

Built to stay out of the way

Everything is optional

Each feature has its own switch, and most have settings, in the options page.

Your token stays local

A read-only token, kept in your browser and sent only to the GitHub API.

Looks like GitHub

GitHub's own colors, light and dark themes, and nothing that moves the page around.

Ready in two minutes

    From the Chrome Web Store or Firefox Add-ons.

  2. 02

  3. 03

    Open a PR list

    The badges appear on the next page load.

Questions

Why does it need a token?

The PR list badges and the reviewer load ask the GitHub API for data the page does not show. Quick comments and the image modal work without one.

Does it work alongside Refined GitHub?

Yes. The two run side by side.
