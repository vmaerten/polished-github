A browser extension for people who review code on GitHub

Four moments of a review day, each one a few clicks shorter.

Triage, assign, reply, read. GitHub Power adds what is missing at each step, in GitHub's own look, and nothing else.

01 Triage 02 Assign 03 Reply 04 Read
01 · Triage

“What needs me today?”

Today you open each PR to find out whether you already reviewed it, how big it is, and whether anyone touched it this week.

Now the list answers it: your review status, the size, and the idle days, on every row.

Placement
Right column or grey line
Idle after
7 days, adjustable
Drafts
Counted or ignored
02 · Assign

“Who has room for this one?”

Today you pick the usual suspect, and the same two people end up with every review.

Now the reviewers picker shows how many reviews each person already has waiting in the organization.

Grey
0 to 2 waiting
Amber
3 to 5 waiting
Orange
More than 5
03 · Reply

“LGTM.” Again.

Today you type the same three replies a dozen times a week.

Now they are buttons above the comment box. One click posts. Edit the list, and choose whether each one shows on PRs, issues or both.

04 · Read

“What does that screenshot show?”

Today a click opens a new tab, and you lose your place in the review.

Now images open in a zoomable modal on top of the page. Arrow keys go through the comment's images.

What it touches, plainly

The extension talks to GitHub and nothing else.
